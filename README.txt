FLEX SPORTY — WEBSITE STARTER

FILES
- index.html: website structure
- style.css: cream / silk / light-brown responsive styling
- script.js: product catalogue and WhatsApp order links
- assets/: sample product crops from the Instagram screenshot

BEFORE PUBLISHING
1. Confirm that +91 9205141039 is the correct business WhatsApp number.
2. In script.js, update WHATSAPP_NUMBER if needed (country code + number, digits only).
3. Replace sample product images in assets/ with original, high-resolution product photos.
4. Edit the products array in script.js: name, subtitle, price, image, and tag.
5. Confirm all prices, COD advance terms, delivery coverage, return/exchange rules and stock before publishing. The website intentionally tells customers to confirm availability.

TEST LOCALLY
Open index.html in a browser. For best results use VS Code + Live Server.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository, e.g. flex-sporty-store.
2. Upload index.html, style.css, script.js and the assets folder to the repository root.
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for the Pages URL to appear in Settings -> Pages.

NOTE
This is a static storefront. It does not take online payments or manage stock/orders. Orders are initiated through WhatsApp.
